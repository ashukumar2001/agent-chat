# AGENTS.md

Full-stack AI chat app ("Eddy"): React 19 + Vite + TanStack Router + Tailwind 4 frontend in `src/react-app/`, Cloudflare Workers backend (Hono + tRPC + AI SDK + Cloudflare Agents/Durable Objects) in `src/worker/`. D1 + Drizzle, Better Auth, Dodo Payments. Package manager is **bun** (`bun.lock`); use `bun` not npm/pnpm.

## Commands (trust package.json, not README)

- `bun run dev` — Vite + workerd dev server on :5173. Sets `CLOUDFLARE_ENV=development` inline.
- `bun run build` / `build:prod` — `tsc -b` then vite build. This is the typecheck step.
- `bun run lint` — ESLint (flat config, eslint 10).
- No test framework exists and there is **no `typecheck` script** (README's table is stale). Verify with `bun run lint` + `bun run build` or `npx tsc -b`.
- `bun run ui` — `bunx --bun shadcn` for shadcn/ui components; repo-local shadcn skill bundle lives in `.agents/skills/shadcn/`.
- `bun run cf-typegen` — regenerates `worker-configuration.d.ts` from wrangler config (commit the result).
- Deploy: `bun run deploy` (dev env, name "eddy") / `deploy:prod` (--name eddy). No CI workflows exist.

## Environment & DB (common gotchas)

- **No `.dev.vars`.** All config lives in gitignored `.env.development` / `.env.production` (mirror `.env.example`). Scripts set `CLOUDFLARE_ENV=development|production`, which selects the file for drizzle-kit and Dodo Payments config. Worker reads secrets via `process.env.*` (works because `nodejs_compat_populate_process_env` is set).
- wrangler.json defines `development` and `production` envs with **separate D1 databases** (`eddy-ai-chat-db-dev` / `-prod`), Durable Objects `ChatAgent` + `UserSettings`, and the `AI` binding.
- Remote DB work: `db:migrate:dev` / `db:migrate:prod` require `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_DATABASE_ID`, `CLOUDFLARE_D1_TOKEN` in the matching `.env.*` file (drizzle.config.ts reads them).
- `db:migrate-local` applies migrations to wrangler's local D1. `db:studio-local` points at the newest `.sqlite` file in `.wrangler/` — run `bun run dev` once first so the DB exists.
- After schema changes: `bun run db:generate`, then apply. `db:generate-better-auth` regenerates `src/worker/db/auth-schema.ts` from `src/worker/lib/auth.ts`.

## Architecture

- Worker entry: `src/worker/index.ts` — Hono app; `/api/auth/**` (Better Auth), `/trpc/*`, `/agents/**` (Durable Object routing via `agents` + `hono-agents`, requires auth session). Static SPA fallback via `assets.run_worker_first` for `/api/*`, `/trpc/*`, `/agents/*`.
- `ChatAgent` (`src/worker/agents/chat-agent.ts`) extends `AIChatAgent` from `@cloudflare/ai-chat`; resolves model + user API key, streams via AI SDK `streamText`, enforces usage limits. Client connects via `useAgent` with name `${userId}:${chatId}`.
- Models registry: `src/worker/lib/models/data/*.ts` (one file per provider) aggregated by `src/worker/lib/models/index.ts`. `ModelConfig` flags: `vision`, `tools`, `webSearch`, `reasoning`, `apiSdk`. Default model is the (intentionally misspelled) `DEFUALT_MODEL` in `src/worker/lib/config.ts`.
- tRPC routers: `src/worker/routes/` (`chats.ts`, `userSettings.ts`, `payments-trpc.ts`, `usage.ts`, `book.ts`).
- Import aliases (vite + tsconfig): `@/*` → `src/react-app/*`, `@worker/*` → `src/worker/*`.

## Conventions

- React Compiler is enabled (babel `reactCompilerPreset`); still follow the memo/useCallback patterns in `.cursor/rules/ui-guidelines.mdc` (alwaysApply) — it also covers Tailwind v4 specifics (CSS-var theming, `bg-linear-to-*`, container queries).
- Usage/billing (`src/worker/lib/usage.ts`, quota env vars `PRO_PLAN_*`) only applies to users **without** their own API key.
- UI text/icons: shadcn/ui in `src/react-app/components/ui/`, HugeIcons, sonner toasts, streamdown for markdown/code/math rendering.
